# Hisashi Iizawa: 99 Bottles real-loop version

## Classification

Historical exhibit only. Not a compiler fixture, conformance oracle, benchmark,
or project-owned example.

## Provenance

- Author: Hisashi Iizawa.
- Page date: December 29, 2005.
- Historical title: `Malbolge (real loop version)`.
- Archived primary page:
  `https://web.archive.org/web/20231210204430/https://99-bottles-of-beer.net/language-malbolge-995.html`.
- Academic project page:
  `https://www.trs.cm.is.nagoya-u.ac.jp/projects/Malbolge/index.html.en`.

The archived primary page describes the program as using real loop processing.
The Nagoya Malbolge project independently records that Iizawa submitted the
99-bottles program in 2005 and that it was produced by an earlier version of LAL.
The associated research line is documented by Hisashi Iizawa, Toshiki Sakabe,
Masahiko Sakai, Keiichirou Kusakari, and Naoki Nishida.
