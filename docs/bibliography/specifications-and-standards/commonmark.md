## Evidence

### Verified

- CommonMark defines a plain-text structured-document syntax.
- Version 0.31.2 is the current published specification on the official site.
- It defines block and inline parsing including ATX headings, fenced code
  blocks, links, lists, and code spans.

### Unresolved

GitHub rendering includes extensions beyond baseline CommonMark. Repository
Markdown policy may therefore be stricter and is governed separately.
