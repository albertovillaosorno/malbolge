## Repository Use

The root `CITATION.cff` gives software and research tooling a machine-readable
citation. This repository deliberately freezes its citation date at 2026-07-26
so normal Git history does not rewrite references already used by readers.

## Provenance

The CFF project defines a human- and machine-readable citation file for software
and datasets. GitHub documents that a root `CITATION.cff` file is parsed to
provide repository citation metadata and a "Cite this repository" entry.

## Evidence

### Verified

- CFF 1.2.0 is a supported Citation File Format version.
- CFF can describe software with authors, title, repository locations, license,
  abstract, keywords, and a release/citation date.
- GitHub recognizes root `CITATION.cff` files on the default branch.

### Unresolved

No DOI or versioned software release exists yet, so those identifiers are not
invented. The frozen date is repository policy, not a CFF requirement.
