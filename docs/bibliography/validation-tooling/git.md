## Repository Relevance

Git history is the repository's durable change provenance. It records when a
technical decision entered project history and preserves commits used as
internal decision provenance, while external factual claims still require their
actual source records.

## Source Quality And Provenance

The official Git reference documents commit, log, show, diff, notes, tags,
branches, remotes, fetch, push, and related history operations.
