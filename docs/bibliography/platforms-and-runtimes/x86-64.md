# x86-64

## Status

Verified as of 2026-07-26.

## Subject

The 64-bit x86 host architecture represented by Intel 64 and compatible AMD64
implementations.

## Repository Use

x86-64 is a first-class host CPU architecture and planned native-code backend.
The bibliography record identifies authoritative architecture documentation;
repository calling conventions, executable-memory policy, and backend design are
owned by technical contracts.

## Provenance

Intel publishes current Intel 64 and IA-32 Software Developer's Manuals that
describe the architecture and programming environment. The repository uses the
industry-neutral `x86-64` name for its host/backend identity.

## Identity And Version

- Stable identifier: Intel 64 architecture manuals
- Authority: Intel Corporation for the cited Intel 64 manuals.
- Subject: Intel 64 architecture and programming environment.
- Manual page last updated: 2026-06-22 at review time.
- Review date: 2026-07-26.

## License Or Terms

Intel documentation is externally authored material. This repository cites it
and does not redistribute the manuals as project-owned content.

## Evidence

- Intel maintains current developer manuals for its 64-bit architecture.
- Those manuals describe architecture, instruction behavior, system programming,
  and the programming environment needed by a native backend.
- Malbolge's `x86-64` backend identity does not make Intel-specific behavior
  part of guest semantics.

### Unresolved

The exact repository CPU-feature baseline, calling convention, and executable
memory policy remain Malbolge technical decisions rather than consequences of
the cited Intel manuals.
