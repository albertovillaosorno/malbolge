## Repository Relevance

TOML is used by Rust/Cargo configuration and is a candidate serialization for
reproducible experiment manifests and other typed repository configuration.

## Source Quality And Provenance

The official TOML project publishes the 1.0.0 specification and describes a
minimal configuration format intended to map unambiguously to a hash table.

## Verified Claims

- TOML 1.0.0 is a published specification.
- TOML documents are UTF-8.
- TOML defines strings, numbers, booleans, date/time values, arrays, and tables.

## Unresolved Evidence

A future experiment-manifest schema is repository-owned and is not defined merely
by choosing TOML as its serialization syntax.
