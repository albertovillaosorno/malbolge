## Repository Relevance

Markdown is the repository's primary human-readable documentation format.
CommonMark provides a precise baseline syntax for documents consumed by humans,
GitHub, linters, and future documentation validators.

current published specification at the review date.

## Verified Claims

- CommonMark defines a plain-text structured-document syntax.
- Version 0.31.2 is the current published specification on the official site.
- It defines block and inline parsing including ATX headings, fenced code blocks,
  links, lists, and code spans.
