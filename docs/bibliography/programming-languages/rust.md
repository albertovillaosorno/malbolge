## Repository Relevance

Rust is the first planned implementation language for the modern VM and trusted
compiler/verifier components where memory safety and explicit integer/state
models are useful.

## Source Quality And Provenance

reference for the language and documents that Rust language/tool documentation
is released with Rust versions.
