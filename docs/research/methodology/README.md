# Methodology

## Purpose

Catalog `docs/research/methodology/`.

## Owns

Records physically owned by `docs/research/methodology/`.

## Does Not Own

Product semantics, legal permission, source identity, or ordinary engineering.


## Contents

### Repository Research Rule

`scientific-method.md` is the base evidence contract. Every genuine research
record declares a method class, baseline/falsification rule, correctness
boundary, provenance, and evidence/interpretation separation. Method-specific
overlays add requirements rather than replacing the base contract.

`template.md` is the default starting surface for new research records.
