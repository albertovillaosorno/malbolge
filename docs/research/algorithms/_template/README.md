# Research Algorithm Template

Copy this directory only when a task is genuine research rather than ordinary
product engineering. Replace the template identity with the stable algorithm ID
shared by `docs/research/algorithms/<id>/` and `algorithms/<id>/`.

The research record must eventually state a falsifiable question, hypotheses,
related work, correctness oracle, experiment design, results including negative
or null results, threats to validity, and promotion criteria. Add `theory.tex`
only when the investigation has real mathematics to state.
