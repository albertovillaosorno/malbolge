# Technical Documentation

Technical documentation owns repository-authored architecture, target semantics,
compiler and VM contracts, runtime behavior, verification rules, accelerator
interfaces, interoperability engineering, and versioned examples.

- `adr/` contains bounded technical decisions.
- `specification/` contains normative machine and mathematical specifications.
- `contracts/` contains proposed or active behavior contracts used by later
  implementation and validation.
- Subject directories explain current or proposed technical models without
  becoming decision records merely because they are important.

A technical record must distinguish proposed behavior from implemented behavior.
Implementation claims require executable evidence.
