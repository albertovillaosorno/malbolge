\title{Adaptive accelerator resource budgeting Research Model}
\begin{document}
\maketitle
Let $F$ be currently free accelerator memory, $T>0$ total accelerator
memory, and $b_i>0$ the exact resident byte requirement of input item $i$. The
planner reserves
\[
  R(T)=\max(8\,\mathrm{MiB},\lfloor T/16\rfloor)
\]
and exposes usable memory
\[
  U(F,T)=\max(0,F-R(T)).
\]
For fixed per-chunk overhead $h\ge 0$, each emitted contiguous chunk
$[s,e)$ must satisfy
\[
  h+\sum_{i=s}^{e-1} b_i \le U(F,T).
\]
The greedy planner chooses each $e$ maximally while preserving input order. It
rejects the complete plan when any individual item violates
\[
  h+b_i \le U(F,T).
\]
Coarse compute-wave evidence is recorded independently as
\[
  W = N_{\mathrm{SM}} T_{\max},
\]
where $N_{\mathrm{SM}}$ is the measured multiprocessor count and $T_{\max}$
is the measured maximum threads per block. $W$ is capacity metadata, not a
semantic bound and not a throughput claim. Increasing $U$ while holding
$\{b_i\}$ and $h$ fixed cannot reduce the maximal first-chunk item count. No
finite constant $U_{\max}$ is imposed by this planner: when a backend has a
finite per-launch representation bound, additional work is partitioned into more
chunks rather than rejected because device memory exceeds an example size.
