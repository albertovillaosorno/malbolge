# Johannes E. Schindelin: 99 Bottles straight-line demonstration

## Classification

Historical exhibit only. Not a compiler fixture, conformance oracle, benchmark,
or project-owned example.

## Provenance

- Author: Johannes E. Schindelin.
- Page date: April 20, 2005.
- Historical title: `Malbolge (just printing out the lyrics)`.
- Archived primary page:
<!-- jig-ignore-next-line: canonical path or identifier is indivisible -->
  `https://web.archive.org/web/20240620220725/https://99-bottles-of-beer.net/language-malbolge-375.html`.

The archived primary page explains that the program produces compressed and
uuencoded song text, so execution requires decoding and decompressing its
output. Its historical value is therefore different from the later real-loop
program: it demonstrates substantial output generation, not a conventional
looping implementation of the song.
