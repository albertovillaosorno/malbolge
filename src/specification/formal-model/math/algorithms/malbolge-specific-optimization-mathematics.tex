\section{Scope}

This document records algebraic reductions that are already consumed by the
Malbolge runtime. A reduction is admitted only on its stated finite/profile
domain and only while its correspondence evidence remains valid.

\section{Classic crazy chunk factorization}

Let $B=3^5=243$. For classic ten-trit words write
\[
  d=d_0+B d_1,\qquad a=a_0+B a_1,
\]
with $d_0,d_1,a_0,a_1\in\{0,\ldots,B-1\}$. Because crazy is digitwise,
\begin{equation}
  \CrazyN{10}{d}{a}
    = \CrazyN{5}{d_0}{a_0}
      + B\CrazyN{5}{d_1}{a_1}.
  \label{eq:optimization-crazy-chunk}
\end{equation}
Therefore one exact $243\times243=59049$ five-trit table is sufficient for both
halves of every classic crazy operation; a $59049^2$ word-pair table is neither
required nor justified.

\section{Profile-width crazy chunk factorization}

For profile width $N$, let chunk width $k=5$, chunk index $j\geq0$, and
\[
  r_j=\min(k,N-jk).
\]
For every admitted chunk with $r_j>0$, define
\[
  d_j=\left\lfloor\frac{d}{3^{jk}}\right\rfloor\bmod3^{r_j},
  \qquad
  a_j=\left\lfloor\frac{a}{3^{jk}}\right\rfloor\bmod3^{r_j}.
\]
Digit independence gives
\begin{equation}
  \CrazyN{N}{d}{a}
    = \sum_{j=0}^{\lceil N/k\rceil-1}
      3^{jk}\left(\CrazyN{5}{d_j}{a_j}\bmod3^{r_j}\right).
  \label{eq:optimization-crazy-profile-chunks}
\end{equation}
The concrete 14-trit profile instance uses chunks $5+5+4$; 15 trits use
$5+5+5$, and 16 trits use $5+5+5+1$. These are instances of the same rule, not
separate arithmetic definitions.

For any semantic width $N\geq10$, define its physical arithmetic padding width
\[
  P_N=5\left\lceil\frac{N}{5}\right\rceil.
\]
Zero-extend only the final partial chunk to $P_N$ trits. Since every added input
trit is zero and $\CrazyN{1}{0}{0}=1$, define
\[
  C_N=\sum_{i=N}^{P_N-1}3^i=\frac{3^{P_N}-3^N}{2}.
\]
Digit independence gives the exact parametric padding identity
\begin{equation}
  \CrazyN{P_N}{d}{a}=\CrazyN{N}{d}{a}+C_N,
  \qquad
  \CrazyN{N}{d}{a}=\CrazyN{P_N}{d}{a}\bmod3^N,
  \quad 0\leq d,a<3^N.
  \label{eq:optimization-crazy-zero-padded-chunk-projection}
\end{equation}
When $5\mid N$, $P_N=N$ and $C_N=0$, so no padding exists. Otherwise only the
unused high inputs of the final five-trit lookup are zero; its extra high output
trits are data-independent and disappear under projection modulo $3^N$. This
proves arithmetic equivalence only. It does not allocate $3^{P_N}$ semantic
memory and does not establish a performance improvement.

Writing $B=3^5=243$ and $q=\lceil N/5\rceil$, decompose
\[
  d=\sum_{j=0}^{q-1} B^j d_j,
  \qquad
  a=\sum_{j=0}^{q-1} B^j a_j,
\]
where every complete chunk satisfies $0\leq d_j,a_j<B$ and the final partial
chunk carries
only its native semantic trits. The same table then gives
\begin{equation}
  \CrazyN{N}{d}{a}
    = \left(
        \sum_{j=0}^{q-1} B^j\CrazyN{5}{d_j}{a_j}
      \right)\bmod3^N,
  \qquad q=\left\lceil\frac{N}{5}\right\rceil,
  \quad N\geq10.
  \label{eq:optimization-crazy-uniform-chunk-factorization}
\end{equation}
Thus one exact $243\times243$ table is reusable for any semantic width. The
number of invocations is $\lceil N/5\rceil$; only the final partial lookup is
zero-padded, and only its nonsemantic high result trits are discarded. This is
an exact factorization, not a wall-clock speedup claim.

\section{Profile-width projection and finite certificates}

For checked widths $10\leq N<M\leq14$, write $W_N=3^N$, $W_M=3^M$,
$\pi_N(x)=x\bmod W_N$, and decompose $x=qW_N+r$ with
$0\leq r<W_N$. Since $0\leq q<3^{M-N}\leq3^4$, direct radix arithmetic gives
\begin{equation}
  \begin{aligned}
    \frac{W_M}{W_N} &= 3^{M-N}, \\
    \pi_N(\operatorname{succ}_M(x)) &= \operatorname{succ}_N(r), \\
    \pi_N(\CrazyN{M}{d}{a})
      &= \CrazyN{N}{\pi_N(d)}{\pi_N(a)}, \\
    \pi_N(\RotateN{M}{x})
      &= \left\lfloor\frac{r}{3}\right\rfloor
         +(q\bmod3)3^{N-1}.
  \end{aligned}
  \label{eq:optimization-profile-width-projection-audit}
\end{equation}
The rotation therefore commutes with projection exactly when
$q\bmod3=r\bmod3$, equivalently when trit $N$ of $x$ equals trit zero.
Different candidate widths inspect different high trits, so this condition is
not monotone in $N$. For any checked subset
$S\subseteq\{10,11,12,13\}$, the conditions $x_N=x_0$ for $N\in S$ constrain
$|S|$ otherwise independent trits, so
\begin{equation}
  \left|\left\{x\in\WordDomain{14}:
      x_N=x_0\text{ for every }N\in S\right\}\right|
    = 3^{14-|S|}.
  \label{eq:optimization-profile-width-rotate-compatible-count}
\end{equation}
One candidate width therefore admits one third of the words, while simultaneous
compatibility with widths 10 through 13 admits exactly $3^{10}=59049$ words.
This is a primitive compatibility count only, not a program-width certificate.
Also, because $W_N$ is coprime to $256$ and $q<256$,
$x\bmod256=r\bmod256$ holds exactly when $q=0$. Therefore
\begin{equation}
  \left|\left\{x\in\WordDomain{M}:
    x\bmod256=\pi_N(x)\bmod256\right\}\right|=3^N,
  \quad 10\leq N<M\leq14.
  \label{eq:optimization-profile-width-output-compatible-count}
\end{equation}
The compatible words are exactly $\WordDomain{N}$ embedded in
$\WordDomain{M}$, so output compatibility is nested monotonically as $N$
decreases. The wide EOF word projects to the narrow EOF word, but for $M>N$
their output bytes differ. Thus small addresses or low projected words alone
are not a semantic narrowing proof.

Let $L(s)$ be the non-whitespace source-word count and let
$\mathsf{LoadOK}_N(s)$ mean that the common lexical/decode admission rules
accept $s$ at checked width $N$. Those rules are width-independent except for
the memory-capacity bound, hence
\begin{equation}
  10\leq N<M\leq14
  \quad\Longrightarrow\quad
  \mathsf{LoadOK}_N(s)\Longrightarrow\mathsf{LoadOK}_M(s).
  \label{eq:optimization-profile-width-source-admission-monotonicity}
\end{equation}
Indeed, admission at $N$ gives $2\leq L(s)\leq W_N<W_M$, while every source
byte and loaded position is unchanged.

When both loads succeed, write $M_0^{(N)}$ and $M_0^{(M)}$ for their complete
initial memories. The loaded source prefix is identical, and for every
remaining narrow address the recurrence plus crazy projection gives
\begin{equation}
  M_0^{(N)}[k]=\pi_N\!\left(M_0^{(M)}[k]\right),
  \qquad 0\leq k<W_N.
  \label{eq:optimization-profile-width-initial-memory-projection}
\end{equation}
The proof is induction on $k$. Source cells are the base case; every recurrence
cell follows by applying the previously proved projection identity to the two
preceding related cells. Thus loader recurrence introduces no additional
width-specific obstruction once source capacity and source admission hold.

For a graphical code cell $m$, write a wide code pointer as
$c_M=qW_N+c_N$ with $0\leq c_N<W_N$. The decode table $X_1$ is injective, so
its outputs agree exactly when the two phase indices agree. Since
$\gcd(W_N,94)=1$ and $0\leq q<3^{M-N}\leq81<94$,
\begin{equation}
  \fitmath{%
    \DecodeOp(m,c_M)=\DecodeOp(m,c_N)
    \Longleftrightarrow q=0
    \Longleftrightarrow c_M<W_N,
    \qquad
    \left|\{c_M<W_M:\text{decode-compatible}\}\right|=W_N.
  }
  \label{eq:optimization-profile-width-decode-compatible-count}
\end{equation}
Thus a continuing graphical lockstep transition cannot justify decode by
pointer projection alone: the wide code pointer must already lie in the narrow
address domain.

Self-encryption has no corresponding width arithmetic. For every graphical cell
$m\in G=\{33,\ldots,126\}$, $\EncryptOp(m)\in G$ and $G\subset\WordDomain{N}$
for every checked width, hence
\begin{equation}
  \pi_N\!\left(\EncryptOp(m)\right)=\EncryptOp(m),
  \qquad 10\leq N\leq14.
  \label{eq:optimization-profile-width-encryption-invariance}
\end{equation}
This proves only transformation invariance. A certificate must still establish
that both executions select the same graphical encryption target after the
instruction-specific effect.

Input assignment itself commutes with checked-width projection. For an available
byte $b\in\{0,\ldots,255\}$ both widths store the same value, while EOF stores
the corresponding all-two-trit word, so
\begin{equation}
  \pi_N\!\left(\operatorname{Input}_M(z)\right)
    = \operatorname{Input}_N(z),
  \qquad
  z\in\{0,\ldots,255,\mathrm{EOF}\}.
  \label{eq:optimization-profile-width-input-projection}
\end{equation}
This does not imply later output compatibility: the wide and narrow EOF words
project to one another but have different byte residues modulo 256.

Finally, let $G=\{33,\ldots,126\}$ and decompose one wide fetched word as
$x=qW_N+r$. Because $W_N>126$, the graphical classifications disagree exactly
when $q>0$ and $r\in G$. Therefore
\begin{equation}
  \left|\left\{x\in\WordDomain{M}:
    \mathbf{1}_G(x)\neq\mathbf{1}_G(\pi_N(x))\right\}\right|
    =94\left(3^{M-N}-1\right).
  \label{eq:optimization-profile-width-graphical-fetch-mismatch-count}
\end{equation}
Every such mismatch is a potential termination divergence: the wide machine
sees a non-graphical cell while the projected narrow machine sees a graphical
cell. A whole-program certificate must exclude these reachable fetches.

Let $D$ be a declared input domain and let $R$ be a finite relation between
complete width-$M$ and width-$N$ guest states. Define
$\mathsf{WidthCert}_{M\to N}(D,R)=1$ only when every input in $D$ maps to a
related initial-state pair, every related pair has equal verifier-required
observations, and every related nonterminal pair either terminates/rejects in
the same observable way or commits one step to another pair in $R$. For
finite deterministic state systems these obligations imply
\begin{equation}
  \mathsf{WidthCert}_{M\to N}(D,R)=1
  \Longrightarrow
  \operatorname{Exec}_M(P,i)\equiv_{\mathrm{obs}}
  \operatorname{Exec}_N(P,i)
  \quad\text{for every }i\in D.
  \label{eq:optimization-profile-width-finite-bisimulation-certificate}
\end{equation}
The proof is induction on committed transition count, with termination handled
by the matching terminal obligation. This theorem supplies a sufficient
certificate shape only; it does not certify any program, infer $D$, or authorize
a product width selector by itself.

For the initial width family, let $c_N(P,D)\in\{0,1\}$ be the independently
verified certificate result for each $N\in\{10,11,12,13\}$. Treat a missing or
invalid result as zero and define
\begin{equation}
  N_*(P,D)
    = \min\left(
        \{N\in\{10,11,12,13\}:c_N(P,D)=1\}\cup\{14\}
      \right).
  \label{eq:optimization-profile-width-minimum-certified-selector}
\end{equation}
This chooses the smallest independently certified width and otherwise returns
the canonical width 14. It assumes no monotonicity of certificate validity
across widths; each narrower candidate remains a separate proof obligation.

\section{Exact crazy-target preimage cardinality}

For one ternary accumulator digit $\alpha\in\{0,1,2\}$ and target digit
$\tau\in\{0,1,2\}$, define the data-digit multiplicity
\[
  \mu(\alpha,\tau)
    = \left|\{\delta\in\{0,1,2\}:\CrazyN{1}{\delta}{\alpha}=\tau\}\right|.
\]
For classic words write the fixed accumulator and target in trits as
$a=\sum_{i=0}^{9}a_i3^i$ and $t=\sum_{i=0}^{9}t_i3^i$. Digit independence
then gives the exact full-data-domain preimage cardinality
\begin{equation}
  \left|\{d\in\WordDomain{10}:\CrazyN{10}{d}{a}=t\}\right|
    = \prod_{i=0}^{9}\mu(a_i,t_i).
  \label{eq:optimization-crazy-preimage-cardinality}
\end{equation}
This is an exact finite search bound only for the complete classic data-word
domain under one fixed accumulator. It does not claim that an arbitrary corpus
contains every preimage or contains each data word only once. In particular,
for $a=0$ and the all-one-trit target $t=\sum_{i=0}^{9}3^i$, every digit has
$\mu(0,1)=2$, so the exact full-domain cardinality is $2^{10}=1024$. If any
factor is zero, no classic data word can reach the target for that accumulator.

The same digit independence gives a constructive inverse canonical form at
checked widths $1\leq N\leq14$. For a reachable fixed pair $(a,t)$ define the
ordered local inverse set
\[
  D_i(a,t)=\{\delta\in\{0,1,2\}:\CrazyN{1}{\delta}{a_i}=t_i\},
  \qquad r_i=|D_i(a,t)|\in\{1,2\}.
\]
Let $q_i(\delta)$ be the zero-based index of $\delta$ in the increasing order
of $D_i$, and let $R_i=\prod_{h=0}^{i-1}r_h$ with $R_0=1$. Then
\begin{equation}
  \fitmath{%
    \operatorname{rank}_{a,t}(d)
      =\sum_{i=0}^{N-1}q_i(d_i)R_i,
    \qquad
    \{d\in\WordDomain{N}:\CrazyN{N}{d}{a}=t\}
      \overset{\sim}{\longrightarrow}
    \left\{0,\ldots,\prod_{i=0}^{N-1}r_i-1\right\}.
  }
  \label{eq:optimization-crazy-profile-preimage-ranking}
\end{equation}
The inverse decodes the rank in the mixed radices $r_0,\ldots,r_{N-1}$ and
selects the corresponding element of each $D_i$. If exactly $k$ local inverse
sets are doubletons, the canonical domain has exactly $2^k$ ranks. A procedure
whose contract is complete-domain preimage enumeration may therefore construct
exactly those $2^k$ data words without testing any of the other $3^N-2^k$
words. This is a finite search-space identity, not a claim about membership in
an incomplete external corpus or about wall-clock speed.

The same doubleton positions form an exact binary hypercube. Let
$J=\{j_0,\ldots,j_{k-1}\}$ contain the positions with $r_i=2$, let
$H_3(x,y)=|\{i:x_i\neq y_i\}|$ be trit Hamming distance, and define
$U_{a,t}(b)$ by selecting bit $b_h$ from the ordered doubleton $D_{j_h}$ while
holding every singleton position fixed. For the binary-reflected Gray code
$G_k(r)=\operatorname{bits}_k(r\mathbin{\oplus}\lfloor r/2\rfloor)$,
\begin{equation}
  \fitmath{%
    U_{a,t}:\{0,1\}^k
      \overset{\sim}{\longrightarrow}
      \{d\in\WordDomain{N}:\CrazyN{N}{d}{a}=t\},
    \qquad
    H_3\!\left(U_{a,t}(G_k(r)),U_{a,t}(G_k(r+1))\right)=1,
    \quad 0\leq r<2^k-1.
  }
  \label{eq:optimization-crazy-profile-preimage-gray-enumeration}
\end{equation}
Thus a complete-domain preimage traversal can visit all $2^k$ compatible data
words exactly once with one trit change between consecutive candidates and no
visits to the other $3^N-2^k$ words. This is an exact traversal identity for
reachable fixed pairs at checked widths $1\leq N\leq14$; it does not assert
external-corpus membership or a wall-clock speedup.

This Gray traversal is also edit-optimal under trit Hamming distance. For any
bijection
\[
  \pi:\{0,\ldots,2^k-1\}
    \overset{\sim}{\longrightarrow}
    \{d\in\WordDomain{N}:\CrazyN{N}{d}{a}=t\},
\]
define its aggregate trit-edit cost by
$E_3(\pi)=\sum_{r=0}^{2^k-2}H_3(\pi(r),\pi(r+1))$. Consecutive values of a
bijection are distinct, so every summand is at least one. The Gray bijection
$\pi_G(r)=U_{a,t}(G_k(r))$ attains equality term by term, hence
\begin{equation}
  \min_{\pi}E_3(\pi)=2^k-1,
  \qquad
  E_3(\pi_G)=2^k-1,
  \quad 0\leq k\leq N,\ 1\leq N\leq14.
  \label{eq:optimization-crazy-profile-preimage-gray-optimality}
\end{equation}
The zero-dimensional case has one preimage and zero edits. This is an exact
minimum only for bijective complete-domain preimage traversal under trit Hamming
cost; it is not a wall-clock lower bound and does not constrain incomplete or
revisiting external-corpus searches.

The same cube coordinates identify the exact one-trit mutation graph. For a
reachable fixed pair, let $G_{a,t}$ have the compatible data words as vertices
and an edge $\{x,y\}$ exactly when $H_3(x,y)=1$. Under $U_{a,t}$, two vertices
are adjacent exactly when their binary coordinates differ in one bit, so
$G_{a,t}\cong Q_k$. Consequently every compatible word has degree $k$ and
\begin{equation}
  \fitmath{%
    \deg_{G_{a,t}}(d)=k,\qquad
    |E(G_{a,t})|=
    \begin{cases}
      0, & k=0,\\
      k2^{k-1}, & 1\leq k\leq N,
    \end{cases}
    \quad 0\leq k\leq N,\ 1\leq N\leq14.
  }
  \label{eq:optimization-crazy-profile-preimage-cube-graph}
\end{equation}
Thus a fixed-pair local search can generate every valid one-trit neighbor by
flipping one ambiguous cube coordinate rather than scanning unrelated data
words. This is an exact complete-domain neighborhood identity; it does not
assert external-corpus membership or a wall-clock speedup.

The full permutation group on the $k$ ambiguous coordinates gives an exact
canonical quotient for coordinate-symmetric analyses. Let $S_k$ act on
$z\in\{0,1\}^k$ by permuting coordinates, let $|z|_1$ be Hamming weight, and
let $c_k(j)$ be the word whose first $j$ coordinates are one and whose remaining
coordinates are zero. Coordinate permutations preserve weight, while any two
words of equal weight can be permuted to the same $c_k(j)$. Therefore
\begin{equation}
  \fitmath{%
    \{0,1\}^k/S_k \overset{\sim}{\longrightarrow} \{0,\ldots,k\},
    \qquad [z]\longmapsto |z|_1,
    \qquad |[z]|=\binom{k}{|z|_1},
    \qquad c_k(j)=1^j0^{k-j},
    \quad 0\leq k\leq N,\ 1\leq N\leq14.
  }
  \label{eq:optimization-crazy-profile-preimage-cube-permutation-quotient}
\end{equation}
Transporting this action through $U_{a,t}$ gives exactly $k+1$ abstract
preimage-cube orbit representatives instead of $2^k$ cube words. This quotient
is valid only for an analysis or objective invariant under arbitrary relabeling
of the ambiguous coordinates; it is not semantic equivalence for
position-sensitive Malbolge execution, numeric word value, layout, or code.

The same coordinate action also gives an exact canonical quotient for ordered
cube-word pairs. For $x,y\in\{0,1\}^k$, define
$n_{uv}(x,y)=|\{h:(x_h,y_h)=(u,v)\}|$ for $u,v\in\{0,1\}$. Let the same
$\sigma\in S_k$ act simultaneously on both pair components, and let
\[
  \mathcal{J}_k=\left\{(n_{00},n_{01},n_{10},n_{11})\in
    \{0,\ldots,k\}^4:\sum_{u,v}n_{uv}=k\right\}.
\]
Simultaneous coordinate permutations preserve these four counts. Conversely,
grouping coordinates into the joint blocks $11,10,01,00$ maps every ordered
pair with the same count vector to one canonical representative. There are
$\binom{k+3}{3}$ nonnegative four-part count vectors summing to $k$. For fixed
counts, choosing which coordinates occupy the four blocks gives exactly
$k!/(n_{00}!n_{01}!n_{10}!n_{11}!)$ ordered pairs in that orbit. Therefore
\begin{equation}
  \fitmath{%
    \left(\{0,1\}^k\times\{0,1\}^k\right)/S_k
      \overset{\sim}{\longrightarrow}\mathcal{J}_k,
    \qquad [(x,y)]\longmapsto(n_{00},n_{01},n_{10},n_{11}),
    \qquad |\mathcal{J}_k|=\binom{k+3}{3},
    \qquad |[(x,y)]|=\frac{k!}{n_{00}!n_{01}!n_{10}!n_{11}!},
    \quad 0\leq k\leq N,\ 1\leq N\leq14.
  }
  \label{eq:optimization-crazy-preimage-cube-ordered-pair-quotient}
\end{equation}
Writing $w_x=|x|_1$, $w_y=|y|_1$, and
$d=|\{h:x_h\neq y_h\}|$ gives
$n_{00}=k-(w_x+w_y+d)/2$, $n_{01}=(-w_x+w_y+d)/2$,
$n_{10}=(w_x-w_y+d)/2$, and $n_{11}=(w_x+w_y-d)/2$. Thus the familiar triple
$(w_x,w_y,d)$ is an equivalent complete orbit key. The chosen block order gives
$c_x=1^{n_{11}+n_{10}}0^{n_{01}+n_{00}}$ and
$c_y=1^{n_{11}}0^{n_{10}}1^{n_{01}}0^{n_{00}}$, agreeing with $c_k$ on
fixed-zero and diagonal pair slices. Transport through $U_{a,t}$ gives exactly
$\binom{k+3}{3}$ canonical ordered cube-word pairs instead of $4^k$ abstract
ordered pairs. Endpoint order remains visible because $n_{01}$ and $n_{10}$ are
distinct, and $H_3(U_{a,t}(x),U_{a,t}(y))=n_{01}+n_{10}$. The quotient applies
only when an ordered-pair analysis is invariant under simultaneous
ambiguity-coordinate relabeling; it is not position-sensitive Malbolge semantic
equivalence or a wall-clock speedup claim.

The same coordinate action extends to ordered cube-word triples. For
$x,y,z\in\{0,1\}^k$, let $n_{uvw}$ count coordinates with joint pattern
$(x_h,y_h,z_h)=(u,v,w)$, and let $S_k$ act simultaneously on all three words.
Define
\[
  \mathcal{J}^{(3)}_k=\left\{(n_s)_{s\in\{0,1\}^3}:
    n_s\in\{0,\ldots,k\},\ \sum_s n_s=k\right\}.
\]
The eight counts are complete orbit invariants: grouping coordinates in
descending binary block order $111,110,\ldots,000$ gives one canonical triple
per count vector. Therefore
\begin{equation}
  \fitmath{%
    \left(\{0,1\}^k\right)^3/S_k
      \overset{\sim}{\longrightarrow}\mathcal{J}^{(3)}_k,
    \qquad
    |\mathcal{J}^{(3)}_k|=\binom{k+7}{7},
    \qquad
    |[(x,y,z)]|=\frac{k!}{\prod_s n_s!},
    \quad 0\leq k\leq N,\ 1\leq N\leq14.
  }
  \label{eq:optimization-crazy-preimage-cube-ordered-triple-quotient}
\end{equation}
At $k=14$, this gives 116280 classes instead of $8^{14}=4398046511104$ raw
ordered triples. The descending block convention reduces exactly to the
existing ordered-pair
representative when the third word is zero, and to the single-word Hamming-
weight representative when the second and third words are zero. The quotient
applies only to triple analyses invariant under simultaneous ambiguity-
coordinate relabeling; it is not position-sensitive Malbolge semantic
equivalence or a wall-clock speedup claim.

If triple endpoint order is also irrelevant, let $S_3$ permute the three words
and hence the eight labels of a joint-count vector. A transposition has four
fixed labels and two two-cycles, while a three-cycle has two fixed labels and
two three-cycles. Define
\[
  \tau_k=\sum_{b=0}^{\lfloor k/2\rfloor}
    \binom{k-2b+3}{3}(b+1),
  \qquad
  \chi_k=\sum_{b=0}^{\lfloor k/3\rfloor}(k-3b+1)(b+1).
\]
These are respectively the numbers of coordinate-quotient classes fixed by one
endpoint transposition and one endpoint three-cycle. Burnside's lemma gives
\begin{equation}
  \fitmath{%
    \left|\mathcal{J}^{(3)}_k/S_3\right|

    \left|\left\{d\in\WordDomain{N}:\CrazyN{N}{d}{a}=t\right\}\right|
    =\frac{9^N}{7^N}=\left(\frac{9}{7}\right)^N,
  \qquad 1\leq N\leq14.
  \label{eq:optimization-crazy-profile-mean-preimage-count}
\end{equation}
This mean is over reachable pairs only and follows from exact input-mass
accounting, not from a probabilistic model of an external candidate corpus. It
is search-planning evidence and carries no runtime-speedup claim.

The same class distribution gives the exact second moment and variance of the
complete-domain preimage cardinality over uniformly chosen reachable pairs:
\begin{equation}
  \begin{aligned}
    \mathbb{E}[M_N^2]
      &= \frac{13^N}{7^N}=\left(\frac{13}{7}\right)^N,\\
    \operatorname{Var}(M_N)
      &= \left(\frac{13}{7}\right)^N
       - \left(\frac{9}{7}\right)^{2N},
    \qquad 1\leq N\leq14,
  \end{aligned}
  \label{eq:optimization-crazy-profile-preimage-variance}
\end{equation}
where $M_N$ is the complete preimage cardinality of a uniformly selected
reachable accumulator/target pair. This is exact dispersion evidence for
complete-domain search planning only; it does not model an external corpus or
imply a runtime-speedup distribution.

Equivalently, for $K_N=\log_2 M_N$ over reachable pairs, the preimage exponent
is exactly binomial:
\begin{equation}
  \fitmath{%
    \Pr[K_N=k]
      = \binom{N}{k}\left(\frac{2}{7}\right)^k
        \left(\frac{5}{7}\right)^{N-k},\qquad
    \mathbb{E}[K_N]=\frac{2N}{7},\qquad
    \operatorname{Var}(K_N)=\frac{10N}{49},
    \quad 0\leq k\leq N,\ 1\leq N\leq14.
  }
  \label{eq:optimization-crazy-profile-log-preimage-binomial}
\end{equation}
This describes exact multiplicity classes under uniform selection from the
reachable complete-domain pair set. It is not a distributional assumption about
an external candidate corpus and carries no timing claim.

For a nonnegative integer full-domain enumeration budget $B$, the same exact
preimage classes give the number of reachable accumulator/target pairs whose
complete data-word preimage cannot fit within that budget:
\begin{equation}
  N_{>B}
    = \sum_{\substack{0\leq k\leq10\\ 2^k>B}}
      \binom{10}{k}2^k5^{10-k}.
  \label{eq:optimization-crazy-preimage-budget-exceedance}
\end{equation}
Thus $N_{>0}=7^{10}$ and $N_{>1024}=0$. This is an exact planning lower bound
only for a procedure that must enumerate every complete-domain preimage of each
pair. It does not imply that an incomplete external corpus contains those
preimages, that every search algorithm must enumerate them, or that a budgeted
search is semantically incorrect when completeness is not its contract.

The same threshold extends to the bounded width family above. For
$N\in\{1,\ldots,14\}$ and nonnegative integer $B$, define
\begin{equation}
  N^{(N)}_{>B}
    = \sum_{\substack{0\leq k\leq N\\ 2^k>B}}
      \binom{N}{k}2^k5^{N-k}.
  \label{eq:optimization-crazy-profile-preimage-budget-exceedance}
\end{equation}
Then $N^{(N)}_{>0}=7^N$ and $N^{(N)}_{>2^N}=0$. The bound inherits the
same complete-domain assumption as the classic equation. It does not claim that
a search over an incomplete corpus must enumerate every preimage, and it carries
no timing or runtime-speed conclusion.

The same ordered classes can be inverted to answer an exact coverage-budget
question. Define
\[
  C_N(k)=\sum_{j=0}^{k}\binom{N}{j}2^j5^{N-j}.
\]
For an integer target $Q\in\{0,\ldots,7^N\}$, the least nonnegative complete-
preimage budget that covers at least $Q$ reachable accumulator/target pairs is
\begin{equation}
  B_N(Q)=\begin{cases}
    0, & Q=0,\\
    \min\{2^k:C_N(k)\geq Q,\ 0\leq k\leq N\}, & 1\leq Q\leq7^N,
  \end{cases}
  \qquad 1\leq N\leq14.
  \label{eq:optimization-crazy-profile-minimum-coverage-budget}
\end{equation}
Because positive preimage sizes are exactly the powers of two, for $k\geq1$
no integer budget below $2^k$ covers a class beyond $k-1$; for $k=0$, budget
zero covers no positive-preimage pair and budget one reaches the first class.
Thus the selected power of two is minimal among all integer budgets, not merely
among class labels. This is exact planning evidence only for procedures that
promise complete-preimage enumeration; it does not model incomplete corpora or
imply runtime speedup.

The unreachable accumulator/target region is the exact complement of the
reachable region inside the complete $9^{10}$ pair domain:
\begin{equation}
  \left|\left\{(a,t)\in\WordDomain{10}^{2}:
    \nexists d\in\WordDomain{10},\ \CrazyN{10}{d}{a}=t\right\}\right|
    =9^{10}-7^{10}=3204309152.
  \label{eq:optimization-crazy-unreachable-pair-count}
\end{equation}
This count rejects only complete-domain impossibility. It does not imply that a
reachable pair occurs in any incomplete external candidate corpus or that
checking membership is free.

For the same bounded width family, the unreachable complement scales exactly as
\begin{equation}
  \left|\left\{(a,t)\in\WordDomain{N}^{2}:
    \nexists d\in\WordDomain{N},\ \CrazyN{N}{d}{a}=t\right\}\right|
    =9^N-7^N,\qquad 1\leq N\leq14.
  \label{eq:optimization-crazy-profile-unreachable-pair-count}
\end{equation}
This is the complement of the independently checked $7^N$ reachable class sum
inside the complete $9^N$ accumulator/target domain. It is an impossibility
count only; it does not infer corpus membership or search/runtime cost.

\section{Decode phase reduction}

For graphical cell $m$, define the exact decode sum class
\[
  s(m,c)=(m-33+c)\bmod94.
\]
The preserved historical $X_1$ table is a permutation of all 94 graphical
bytes. Hence
\begin{equation}
  \DecodeOp(m,c)=X_1[s(m,c)],
  \qquad
  \DecodeOp(m,c)=\DecodeOp(m',c')
  \Longleftrightarrow s(m,c)=s(m',c').
  \label{eq:optimization-decode-phase}
\end{equation}
Thus the $94\times94=8836$ graphical-cell/code-phase pairs form exactly 94
decode-equivalence classes of size 94. A boundary whose only observable is the
decoded opcode may retain $s(m,c)$ instead of the pair $(m,c\bmod94)$. This does
not identify whole machine states: raw cell or code-pointer identity must remain
when encryption, control flow, source location, or another downstream semantic
uses them separately.


\section{Self-encryption orbit canonicalization}

Let $G=\{33,\ldots,126\}$ be the graphical-cell domain and let
$E:G\to G$ be the Malbolge self-encryption permutation $E(m)=\EncryptOp(m)$.
The exact $X_2$ table partitions $G$ into six disjoint cycles whose lengths are
\[
  \{2,4,5,6,9,68\}.
\]
For a cell $m\in G$, write $\ell(m)$ for the length of its unique cycle. Then
for every visit count $k\in\mathbb{N}$,
\begin{equation}
  E^k(m)=E^{k\bmod\ell(m)}(m).
  \label{eq:optimization-encryption-orbit}
\end{equation}
Therefore a search state that tracks only repeated committed self-encryption of
one unchanged code-cell address may replace an unbounded encryption-visit count
by the canonical residue $k\bmod\ell(m)$. The reduction applies only when each
counted visit reaches the normative post-instruction encryption phase. Halt,
rejected transitions, writes that change the cell by another mechanism, and
control-flow/address equivalence remain outside this reduction.

\section{Classic rotate lookup}

The classic word domain is finite, so define a table $R$ by
\begin{equation}
  R[x]=\RotateN{10}{x}
  \qquad\text{for every }x\in\WordDomain{10}.
  \label{eq:optimization-rotate-table}
\end{equation}
Replacing scalar rotation by $R[x]$ is an exact finite-domain substitution, not
an approximation or heuristic.

\section{Classic rotate-history canonicalization}

Let $R$ now denote one normative right rotation of a classic ten-trit word. A
rotation permutes the ten trit positions cyclically, so applying ten rotations
restores every word. Therefore, for every $x\in\WordDomain{10}$ and visit count
$k\in\mathbb{N}$,
\begin{equation}
  R^k(x)=R^{k\bmod 10}(x).
  \label{eq:optimization-rotate-history}
\end{equation}
This gives a safe universal canonical bound, but the exact period can be
sharpened per word. Define
\[
  p(x)=\min\{d\in\{1,2,5,10\}:R^d(x)=x\}.
\]
Every rotation period divides ten, and exhaustive classification of the classic
word domain gives
\begin{equation}
  \left|\{x:p(x)=d\}\right|=
  \begin{cases}
    3, & d=1,\\
    6, & d=2,\\
    240, & d=5,\\
    58800, & d=10.
  \end{cases}
  \qquad
  R^k(x)=R^{k\bmod p(x)}(x).
  \label{eq:optimization-rotate-minimal-period}
\end{equation}
The counts partition all $3^{10}=59049$ classic words. Therefore a search state
tracking repeated rotate updates to one otherwise unchanged classic data cell
may use the word-specific residue modulo $p(x)$ instead of the universal residue
modulo ten. Intervening writes or a changed data-pointer identity fall outside
this reduction, and the result carries no runtime-speed claim.

\section{Verified candidate boundary}

Let $C$ be a candidate set, $V(c,p)\in\{0,1\}$ the independent verifier under
profile $p$, and $\CostVector{c}$ the measured cost vector. Search may rank or
generate candidates arbitrarily, but only
\[
  C_V=\{c\in C\mid V(c,p)=1\}
\]
is eligible for cost comparison. A speedup cannot repair failed semantic
correspondence.

\section{Measured implementation result}

The versioned CPU VM benchmark evidence is stored under
\path{benchmarks/interpreter/evidence/} in the
\texttt{2026{-}07{-}26{-}windows{-}x86\_64/} directory. It contains 15 raw
samples per scalar/table implementation and identical checksums. On that
identified host, the classic crazy factorization reduced the median from
77,456,700 ns to 7,423,600 ns (10.43x), while rotate lookup reduced the median
from 15,260,300 ns to 10,141,700 ns (1.50x). These measurements justify the
current CPU implementation on that recorded workload; they are not universal
hardware performance claims.
